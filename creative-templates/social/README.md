# Referências de posts

Artes quadradas criadas como referências de composição para o workflow de posts. Os textos são marcadores visuais: a IA deve substituir título, apoio e CTA de acordo com o briefing, sem inventar promoções.

Os arquivos terminados em `-background.png` são os fundos produtivos, sem texto, CTA ou logo. Publique e cadastre estes arquivos no Hub. As versões sem esse sufixo são apenas mockups para visualizar a composição final.

| Arquivo | Plataforma | Aparência | Cores principais |
| --- | --- | --- | --- |
| `purple-dark.png` | Purple | Escura | `#0B0B0E`, `#9A47F6`, `#C494F9` |
| `purple-light.png` | Purple | Clara | `#F7F4FA`, `#7540B8`, `#9A47F6` |
| `green-kick-dark.png` | Green / Kick | Escura | `#080A08`, `#53FC18`, `#18D500` |
| `green-kick-light.png` | Green / Kick | Clara | `#F3F8F3`, `#167A2D`, `#53FC18` |

Fundos produtivos correspondentes:

- `purple-dark-background.png`
- `purple-light-background.png`
- `green-kick-dark-background.png`
- `green-kick-light-background.png`

Depois de publicar os arquivos, cadastre no Hub as URLs HTTPS diretas das imagens. Não use a URL de uma página ou publicação; o endereço deve responder com o próprio arquivo PNG.
